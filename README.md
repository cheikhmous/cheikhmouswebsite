# CV-website Cheikhmous Hamed

Statische website zonder build-stap: `index.html`, `styles.css` en `script.js`.

## Lokaal bekijken
Open `index.html` in je browser.

## Op GitHub Pages zetten
1. Maak een nieuwe repository op GitHub (bijvoorbeeld `cv`).
2. Upload alle bestanden, of gebruik `git add .`, `git commit` en `git push`.
3. Ga naar Settings, Pages, kies de branch `main` en de map `/ (root)`, en klik op Save.
4. Na een minuut staat de site op `https://<jouw-gebruikersnaam>.github.io/<repo-naam>/`.

## Aanpassen
- Tekst: `index.html`
- Animatie en knoppen: `script.js`
- Kleuren en lettertypen: bovenaan `styles.css` (variabelen onder `:root`)
